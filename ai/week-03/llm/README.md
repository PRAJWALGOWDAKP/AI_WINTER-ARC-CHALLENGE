How Large Language Models (LLMs) Work
1. What is an LLM?
A Large Language Model (LLM) is an AI model trained on large amounts of text to learn language patterns and generate text-like responses.

Examples include ChatGPT, Google Gemini, and Claude.
2. Tokens
A token is a unit of text that a model processes. It can be:
- A whole word
- Part of a word
- Punctuation
- Sometimes a single character
For example, I love learning AI may be split into tokens such as I, love, learning, and AI. Actual tokenization depends on the model.

Why tokens matter:
- Input text is converted into tokens before the model processes it.
- The model generates its response as a sequence of tokens.
- Token counts affect context limits, processing time, and cost.
3. Next-Token Prediction
LLMs commonly generate text by predicting the next token, based on the tokens that came before it.

Example:
- Prompt: I love
- Possible next token: learning
- New sequence: I love learning
- Possible next token: AI
- New sequence: I love learning AI
The model repeats this process until it reaches a stopping condition.
How does it learn the correct next token?
During training, the model is shown text from a training dataset. The original text provides the target token.

For example, if the training text is:

The Sun rises in the east.

The model may receive The Sun rises in the as input, with east as the target next token. It predicts a token, its prediction is compared with the target, and a loss function measures the error. An optimization algorithm then adjusts the model's parameters to improve future predictions.

This process is repeated across many training examples.

Important: During normal chatting, the model generally uses its learned parameters and the user's prompt to predict tokens. It is not normally given the original training answer key.
4. Pre-training
Pre-training is the initial, broad training stage used to build a model's general capabilities.
- Developers prepare large training datasets, such as text, books, articles, and code.
- The model learns by predicting tokens from the training examples.
- Its parameters are updated to reduce prediction error.
- Repeated training helps it learn grammar, language patterns, relationships between concepts, and information represented in the data.
Think of pre-training as general education.
5. Fine-tuning
Fine-tuning means training an already pre-trained model further on a more targeted dataset.

For example, developers may use question-and-answer examples to improve how a model responds to Python programming questions or follows instructions.

Fine-tuning can help adapt a model to:
- A particular task or subject area
- A desired response style
- Following instructions more effectively
Fine-tuning adjusts the model's parameters. It does not guarantee perfect answers, and the model may still make mistakes.

Think of fine-tuning as specialized training after general education.
6. Pre-training vs. Fine-tuning
Pre-training	Fine-tuning
Uses broad, large-scale datasets	Uses more targeted datasets
Builds general capabilities	Adapts existing capabilities
Usually computationally expensive	Often less expensive than pre-training
Happens earlier in model development	Happens after pre-training


The training data is prepared by the developers or training-data pipeline—not usually supplied by someone chatting with the model.
7. Overall Workflow
1. Collect training data: Prepare a large dataset.
2. Tokenize text: Convert text into tokens.
3. Pre-train: Predict target tokens and update model parameters.
4. Fine-tune (if needed): Further train the model on targeted examples.
5. Inference: When a user sends a prompt, the trained model generates a response token by token.
Key Takeaways
- Tokens are the units of text processed and generated by an LLM.
- Next-token prediction is the core mechanism used by many LLMs to generate text.
- Pre-training builds broad language capabilities using large datasets.
- Fine-tuning further adapts a pre-trained model for particular tasks or behaviors.
- During ordinary inference, the model uses its learned parameters to generate responses; its parameters are not normally updated just because a user chats with
