1. Context window
The context window is the maximum amount of information a model can process at one time, measured in tokens.

Think of it as the model's working space.

For example, suppose a model has a context window of 100,000 tokens.
- System instructions: 5,000 tokens
- Conversation history: 20,000 tokens
- Your current prompt: 2,000 tokens
- Space available for the response and other processing: depends on the model's limits and configuration.
The context window is shared by the relevant input and output tokens, subject to the model's specific limits. When a conversation gets too long, some earlier content may no longer fit.
2. Temperature
Temperature controls the randomness of the model's output.
Temperature	Typical behavior
0.0	More consistent, predictable responses
0.3	Relatively focused responses
0.7	More varied and creative responses
1.0	Often more diverse output

For example, if you ask, "Suggest a name for my AI chatbot":
- Low temperature: "AI Assistant"
- Higher temperature: "NovaMind", "EchoSphere", or other creative names.
These are illustrative examples, not guaranteed outputs. Temperature does not directly control factual accuracy, and some models or APIs do not expose this setting.
3. Top-p
Top-p, also called nucleus sampling, controls which candidate tokens are considered when generating the next token.
- top_p = 0.1: considers a smaller set of the most likely tokens.
- top_p = 0.5: considers a broader set.
- top_p = 1.0: considers the full probability distribution.
For example, imagine these probabilities for the next token:
Candidate	Probability
Python	0.60
Java	0.25
C++	0.10
Ruby	0.05

With top_p = 0.8, nucleus sampling would include Python and Java, whose cumulative probability is 0.85, because the smallest set reaching at least 0.8 contains both.

Key difference: Temperature reshapes the probability distribution; top-p restricts sampling to a cumulative-probability set. They are different controls, and their effects depend on the model.


# LLM Token Counter

## Overview

This project demonstrates how to count tokens in a text prompt using Python and the `tiktoken` library. It displays the total token count, token IDs, and individual token representations.

## Features

- Count the total number of tokens in a prompt.
- Display all token IDs.
- Display each token alongside its corresponding ID.
- Explore how an LLM tokenizer splits text into tokens.

## Technologies Used

- Python
- [tiktoken](https://github.com/openai/tiktoken)

## Installation

Install `tiktoken` using `uv`:

```bash
uv pip install tiktoken
```

Alternatively, if you manage dependencies through `pyproject.toml`:

```bash
uv add tiktoken
```

## Usage

Run the Python script:

```bash
python count_tokens.py
```

The script uses the `cl100k_base` tokenizer to encode the prompt.

```python
import tiktoken

encoding = tiktoken.get_encoding("cl100k_base")

prompt = "Explain context window, temperature, and top-p."

tokens = encoding.encode(prompt)

print("Prompt:", prompt)
print("Total tokens:", len(tokens))

print("\nToken IDs:")
print(tokens)

print("\nIndividual tokens:")
for token_id in tokens:
    token_text = encoding.decode([token_id])
    print(f"ID: {token_id:<8} Token: {repr(token_text)}")
```

## Example Output

The program displays the original prompt, the total number of tokens, the list of token IDs, and each token's decoded representation.

```text
Prompt: Explain context window, temperature, and top-p.
Total tokens: <number of tokens>

Token IDs:
[...token IDs...]

Individual tokens:
ID: <token ID> Token: <token text>
```

*Note: The actual token count and IDs are generated by the tokenizer when you run the program.*

## Key Concepts Learned

### 1. Token

A token is a unit of text processed by a language model. It can represent a word, part of a word, punctuation, whitespace, or other text.

### 2. Tokenization

Tokenization is the process of converting text into token IDs using a tokenizer.

### 3. Encoding

The `encoding.encode(prompt)` method converts a string into a list of token IDs.

### 4. Decoding

The `encoding.decode([token_id])` method converts a token ID back into a text representation. Decoding individual tokens may sometimes produce replacement characters when a token represents only part of a multibyte character.

### 5. Token Count

The expression `len(tokens)` returns the number of tokens generated for the prompt.

## Important Note

The `cl100k_base` tokenizer is one particular tokenizer. Its token counts may differ from those of other models and tokenizers. Counting a prompt with this script does not reveal the complete hidden context of a running LLM.

## Learning Outcome

This project provides a practical introduction to tokenization and helps build an understanding of how text is represented numerically before being processed by a language model.
