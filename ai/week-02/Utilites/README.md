# Python Comprehensions and Text Processing

## Overview
This project demonstrates Python list comprehensions, dictionary comprehensions, conditional expressions, list slicing, and basic text processing.

## Concepts Covered

### 1. List Comprehensions
- Extract even numbers from a list.
- Calculate the square of each number.
- Retrieve the last three elements using list slicing.

### 2. Dictionary Comprehensions
- Filter students who scored more than 40 marks.
- Assign Pass or Fail status to each student using conditional expressions.

### 3. Text Processing
- Split a paragraph into individual words.
- Count the total number of words.
- Extract the first five words.
- Generate a short summary using the first six words.

## Examples

### List Operations
Input:
```python
n = [1, 2, 3, 4, 5, 6]
```

Expected results:
- Even numbers: `[2, 4, 6]`
- Squares: `[1, 4, 9, 16, 25, 36]`
- Last three numbers: `[4, 5, 6]`

### Student Marks
The program uses a dictionary of student names and marks to:
- Identify students who passed (marks greater than 40).
- Display each student's Pass or Fail status.

### Text Analysis
The program processes a paragraph and displays:
- Total word count.
- First five words.
- A short summary containing the first six words.

## Learning Outcomes
- Write concise and readable code using comprehensions.
- Filter and transform lists and dictionaries.
- Apply conditional logic within comprehensions.
- Manipulate strings using `split()` and `join()`.
- Use list slicing to extract specific elements.

## Technologies Used
- Python 3
- Built-in data structures: lists and dictionaries
- String manipulation methods
